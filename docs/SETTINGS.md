# Настройки

Откройте «Настройки» в панели или выполните `ytm-alice config get`.
Настройки сохраняются на Станции в `var/local.ytm-alice/settings.json`
и переживают перезапуск и обновление пакета. Те же команды доступны в CLI на ПК.

```sh
ytm-alice config set web_addr :24721
ytm-alice daemon restart
ytm-alice config set radio false
ytm-alice config set announce_text "Сейчас включу"
ytm-alice config set announce_errors true
ytm-alice shuffle-on
ytm-alice shuffle-off
```

| Настройка | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `web_addr` | `:24721` | Адрес HTTP-панели; `off` отключает её. Применяется после перезапуска |
| `radio` | `true` | Добавлять похожие треки после последнего трека очереди |
| `shuffle` | `false` | Перемешивать новые очереди; команды `shuffle-on/off` меняют и текущую |
| `announce_text` | `Включаю` | Фраза перед музыкой; пустая строка отключает фразу |
| `announce_errors` | `true` | Сообщать об ошибках запуска штатным голосом |
| `playback_led` | `true` | Подсветка при воспроизведении; отключение доступно для sysfs-колец Лайт 1 и Мини 2 |
| `youtube_only` | `false` | Вся музыка через YouTube: музыкальные запросы Алисы играют здесь, а не в Яндекс Музыке |
| `voice_commands` | `{}` | Дополнительные голосовые команды |

При обновлении установки без `settings.json` сохраняется порт 80. Адреса
показывает `ytm-alice web status`. Переменная `YTM_ALICE_WEB_ADDR` имеет приоритет
над файлом; временная переменная окружения не меняет постоянную настройку.
Если меняете порт с компьютера, после перезапуска обновите подключение:
`ytm-alice connect http://IP_СТАНЦИИ:24721`.

Свои команды можно добавить и сохранить во вкладке «Команды» панели. Эквивалент для CLI:

```sh
ytm-alice config set voice_commands '{"сыграй {query}":"play","замри":"pause","моя подборка":"recommendations"}'
```

`{query}` означает название трека после фразы. Доступные действия:
`play`, `recommendations`, `pause`, `resume`, `stop`, `next`, `previous`, `what`,
`shuffle-on`, `shuffle-off`. Стандартные команды сохраняются.

Слово «ютуб» можно сказать в любом месте фразы: «включи трек Numb с ютуба»
ищет «Numb», «включи ютуб» запускает персональную подборку.

С `youtube_only true` ytm-alice забирает и запросы без слова «ютуб», если облако
Алисы решило включить свою музыку: «включи музыку» и «включи мою волну» запускают
подборку YouTube, «включи Linkin Park» ищет исполнителя, а названный трек — по
названию и исполнителю, которые выбрала Алиса. Признак — директива `audio_play`
с музыкой в ответе облака, поэтому умный дом, таймеры и сказки остаются Алисе.
Ответ Алисы отменяется до начала воспроизведения; если отмена не подтвердится,
Яндекс Музыка может успеть зазвучать.

```sh
ytm-alice config set youtube_only true
```

«Алиса, включи музыку на ютубе» и `ytm-alice recommendations` запускают
персональную подборку подключённого профиля. Радио в конце очереди работает
и без аккаунта, если YouTube возвращает похожие треки. Приём очереди с телефона
сохраняет управление рекомендациями за приложением YouTube Music.

Плейлисты, лайки и библиотека загружаются постранично без прежнего лимита 50.
Сбой на следующей странице сообщается как ошибка, а не как успешно обрезанный
список. Очень большая библиотека может потребовать больше времени.

Подсветка отключается только во время воспроизведения и вне диалога Алисы.
Управление не затрагивает часы, rootfs или системные службы. На других моделях
переключатель недоступен. Отключение кольца и возврат управления Алисе проверены
на реальной Лайт 1; для Мини 2 пока проверен только выбор sysfs-узлов.
